# **Luis Lezama – Portfolio Website**

A modern, responsive portfolio website showcasing my journey, skills, and projects as a software development student. Built with HTML, CSS, and Bootstrap 5, this site highlights my unique background in technology, culinary arts, and creative problem‑solving.

---

## **🌟 Overview**

This portfolio serves as a central hub for my work and personal story. It includes:

- A clean, modern landing page  
- A detailed “About Me” section  
- A skills overview  
- A curated list of projects  
- Contact information  
- Responsive design for mobile and desktop  

The goal is to present my work professionally while reflecting the diverse experiences that shape who I am.

---

## **🛠️ Technologies Used**

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **Google Fonts (Montserrat)**
- **Responsive design principles**
